## Custom repository

We have created a [custom repository](https://blenderdmx.eu/download/) for
BlenderDMX releases. This keeps the release and update process fully under our
control and reduces the risk of being locked out from providing updates to
BlenderDMX users. This release includes the full BlenderDMX feature set,
including network protocols such as sACN, ArtNet, OSC, PSN, MVR-xchange, GDTF
Share integration and so on.

* Rename the package to BlenderDMX in the BlenderDMX.eu repository
* Remove 3D animation data during GDTF file import
* Translated using Weblate:
    - Tamil: தமிழ்நேரம்
    - Spanish: Libre
    - Portuguese: António Oliveira
    - Kazakh: Azamat Аituganov
